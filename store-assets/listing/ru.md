# Страница в магазине — Русский

## Краткое описание (до 132 символов)
Всё для Steam в одном: история цен, инструменты списка желаемого, помощники рынка и инвентаря, региональные цены, ProtonDB.

## Подробное описание

**Steam Enhancer** собирает самые любимые функции популярных расширений для Steam в одном чистом, быстром и безрекламном расширении Manifest V3: история цен и уведомления о минимальной цене, инструменты списка желаемого, помощники для торговой площадки и инвентаря, сводки по предложениям обмена и многое другое. Без телеметрии и без аккаунта.

### Всё о ценах
• Текущая минимальная цена по магазинам и исторический минимум с магазином, датой, скидкой и графиком истории цен (на основе IsThereAnyDeal — нужен бесплатный API-ключ: зарегистрируйте его на isthereanydeal.com/apps/my/ и вставьте в настройках; IsThereAnyDeal требует это от каждого приложения, которое использует их API)
• Ценовые уведомления: задайте целевую цену прямо на странице игры и получите уведомление, когда она будет достигнута
• Уведомления об играх, которые временно раздают бесплатно
• Сравнение региональных цен (US / AR / TR / RU / IN / BR) и вторая валюта отображения по желанию
• Проверка выгоды наборов: покупка по отдельности или набором
• Значок исторического минимума в каждом результате поиска

### Виджеты на странице игры
• Рейтинг ProtonDB для игроков на Steam Deck / Linux
• Быстрая ссылка на HowLongToBeat
• Число игроков онлайн, статистика достижений и разбивка обзоров
• Пометка возможного review bomb и живой фильтр обзоров (минимум часов игры, длина, рекомендуют / не рекомендуют)
• Подсветка имеющихся DLC, ссылки на коллекционные карточки и личные заметки к играм
• Быстрые ссылки на SteamDB, SteamCharts, Barter.vg, SteamSpy и другие
• По желанию: сколько друзей владеют игрой (с вашим собственным ключом Steam Web API)

### Поиск, скидки и распродажи
• Подсветка игр, которые у вас есть, в списке желаемого или в игнорируемых
• По желанию можно скрывать имеющиеся и игнорируемые игры

### Список желаемого
• Экспорт в CSV, JSON или текст в буфер обмена
• Открытие всего списка пакетом в IsThereAnyDeal
• Целевые цены для каждой строки с необязательными фоновыми уведомлениями

### Торговая площадка Steam
• Сумма после комиссий в каждом лоте
• Калькулятор undercut и помощник по заявкам на покупку
• График истории цен и встроенный конвертер валют

### Инвентарь
• Оценка общей стоимости инвентаря с графиком изменения стоимости
• Поиск дубликатов, сортировка по стоимости, группировка по типу
• Продажа нескольких предметов с подтверждением; ничего не выставляется без вашего явного нажатия
• Экспорт инвентаря в JSON

### Предложения обмена
• Таблица стоимости по каждому предмету для обеих сторон
• Локальная история обменов с каждым партнёром, хранится только в вашем браузере

### Профиль, библиотека и значки
• Оценка размера и стоимости библиотеки, сводка по значкам и опыту
• Быстрые ссылки на SteamDB, SteamLadder, Backpack.tf и SteamRep

### Языки
Английский, иврит (RTL), русский, немецкий и португальский (Бразилия).

### Приватность прежде всего
Steam Enhancer **не собирает, не передаёт и не продаёт персональные данные**. Нет аналитики, нет удалённого сервера, аккаунт не нужен. Настройки хранятся в вашем браузере через стандартное хранилище синхронизации Chrome.
