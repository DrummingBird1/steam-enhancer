# בדיקה מחובר ל-Steam לפני שחרור 1.5.0

מה שאי אפשר לבדוק בלי חשבון Steam מחובר. כל השאר נבדק כבר: unit tests (70), smoke test מול Steam החי (11), ודפי בדיקה עם נתונים אמיתיים (ה-wishlist, הגרף, ה-popup, עמוד ההגדרות).

## הכנה

1. `chrome://extensions/` ← מצב מפתח ← **Load unpacked** ← תיקיית הריפו (על ה-branch `release/1.5.0`).
2. אם 1.4.x כבר טעון: להסיר אותו קודם, או ללחוץ Reload ולבדוק שמודאל ה-changelog מופיע בעמוד הבית של החנות.
3. ב-Options ← "מחירים ומפתחות": להדביק מפתח ITAD.
4. להיות מחובר ל-Steam באותו פרופיל של Chrome.
5. לפתוח את **Service worker** בכרטיס התוסף ב-`chrome://extensions/` ולבדוק שאין שגיאות אדומות. כל שגיאה שם רלוונטית.

## 1. מכירה (הכי חשוב)

מוכרים פריט אחד זול (כמה סנטים), כדי לא לסכן כלום.

- [ ] במלאי, לבחור פריט סחיר. מתחת לפרטים מופיעים **מכירה מהירה** ו**מכירה מיידית**.
- [ ] **מכירה מהירה**: מוצגים "הקונה משלם X · אתה מקבל Y" **במטבע הארנק שלך** (₪ אם הארנק בשקלים). X צריך להיות סנט מתחת להצעה הזולה ב-Market. Y צריך להיות בערך X פחות 13%.
- [ ] ללחוץ **אישור**. ההצעה מופיעה ב-Market, ואם יש מאמת נייד, מופיעה בקשת אישור.
- [ ] ב-Market, המחיר שהקונה רואה בהצעה החדשה **זהה ל-X**. זה הבאג שהיה ב-1.4.x, אז זו הבדיקה החשובה ביותר.
- [ ] **מכירה מיידית** על פריט שיש לו הזמנות קנייה: מוצג מחיר שווה להזמנת הקנייה הגבוהה. **לא חובה לאשר.**
- [ ] פריט של Steam עצמו (קלף מסחר / רקע / אימוג'י, appid 753): מכירה מהירה עובדת (ב-1.4.x היא נכשלה).
- [ ] "בחר פריטים למכירה" ← לסמן 2 פריטים ← "הצע את הנבחרים": ליד כל מחיר מופיע "הקונה משלם / אתה מקבל", ומשתנה כשעורכים את המחיר. **לא חובה לאשר.**

## 2. Market

- [ ] בעמוד פריט ב-Market: "תקבל ≈" ליד כל הצעה (בערך 13% פחות מהמחיר).
- [ ] **גרף היסטוריית מחיר**: גרף עם מעבר עכבר וטווחים, במטבע הארנק.
- [ ] **עזרה בהזמנות קנייה**: מוצגות הזמנת הקנייה הגבוהה וההצעה הזולה.
- [ ] בעמוד הבית של ה-Market, מעל "My listings": סרגל עם **בדוק מחירים**. אחרי הבדיקה כל הצעה מסומנת "הזול ביותר" או "נעקף ב-X".
- [ ] "סמן את מי שעקפו" ← "הסר מסומנים" ← אישור: ההצעות יורדות (אפשר להסיר את ההצעה מסעיף 1).

## 3. מלאי ו-Trade

- [ ] "הערך שווי": המספרים במטבע הארנק, לא בדולרים.
- [ ] "היסטוריית שווי" אחרי 2 הערכות: גרף.
- [ ] בהצעת Trade (אפשר לפתוח הצעה חדשה בלי לשלוח): טבלת שווי לשני הצדדים, כולל קלפי מסחר (ב-1.4.x הם הראו 0).

## 4. רשימת משאלות

- [ ] `store.steampowered.com/wishlist/`: הפאנל מופיע **מעל** הרשימה של Steam, והרשימה של Steam עדיין עובדת כרגיל (גלילה, הסרה, מיון).
- [ ] המחירים בטבלה **במטבע שלך**, השפל ההיסטורי מתמלא אחרי כמה שניות, וה-"בשפל עכשיו" הגיוני.
- [ ] מיון, סינון, ייצוא CSV.
- [ ] קביעת "התראה ב-" לשורה ← אותו מחיר מופיע בעמוד המשחק בשדה "התרע לי ב-".
- [ ] רשימת משאלות של חבר (כתובת `/wishlist/id/<name>/`): נטענת.

## 5. עמוד משחק

- [ ] המחיר הנמוך, השפל ההיסטורי, ו**גרף** עם טווחים ומעבר עכבר.
- [ ] Options ← להפעיל "מחירים אזוריים": טבלה מומרת ל-₪, מהזול ליקר, עם "(אתה)".
- [ ] תג Steam Deck. פירוט ביקורות (חיובי/שלילי). אם Steam מוגדר בעברית או בשפה אחרת, הפירוט עדיין מופיע.
- [ ] משחק שבבעלותך + מפתח Steam Web API ב-Options: "ההישגים שלך" עם פס התקדמות.
- [ ] משחק עם "original" בתיאור (למשל משחק remaster): **אין** תג "EA App" מיותר.

## 6. התראות

- [ ] Options: להפעיל "התראה כשמחיר מגיע ליעד". לקבוע יעד **מעל** המחיר הנוכחי של משחק כלשהו.
- [ ] ב-`chrome://extensions/` ← Service worker ← בקונסול: `chrome.alarms.create('se-pricealert-poll', { when: Date.now() + 1000 })`
- [ ] מגיעה התראת מערכת, מופיע מספר על אייקון התוסף, וההתראה מופיעה ב-popup. לחיצה עליה פותחת את המשחק. פתיחת ה-popup מאפסת את המספר.
- [ ] שעות שקטות שכוללות את השעה הנוכחית ← להריץ שוב (אחרי שינוי היעד): אין התראת מערכת, אבל היא כן מופיעה ב-popup.

## 7. הגדרות ו-popup

- [ ] עמוד ההגדרות בעברית (RTL), החיפוש עובד, שינוי נשמר מיד ("נשמר").
- [ ] CSS מותאם, למשל `.se-panel { border-color: red !important; }`, משפיע על עמוד Steam אחרי רענון.
- [ ] ייצוא גיבוי ← איפוס ← ייבוא: הכול חוזר (כולל הערות ויעדי מחיר).

## צילומי מסך לחנות (1280×800)

אחרי שהכול עובד, לצלם מחדש. אלה בחנות הם עדיין של 1.4.1:
1. עמוד משחק עם הפאנל והגרף
2. פאנל רשימת המשאלות
3. עמוד ההגדרות החדש
4. ה-popup עם התראות
5. (אופציונלי) מכירה מהירה במלאי

לשמור ב-`store-assets/` בשמות הקיימים (`screenshot-1-…png` וכו').

## אם משהו לא עובד

לשמור את השגיאה מ-Service worker או מהקונסול של העמוד (F12) ואת כתובת העמוד, ולהעביר אליי.
