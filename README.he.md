# Steam Enhancer

[![Manifest V3](https://img.shields.io/badge/Manifest-V3-blue)](https://developer.chrome.com/docs/extensions/mv3/intro/)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

**גרסה זו בעברית. הגרסה הראשית (אנגלית) נמצאת ב-[README.md](README.md).**

**Steam Enhancer** הוא תוסף Chrome כולל שמוסיף ל-Steam את הפיצ'רים האהובים ביותר מהתוספים *Augmented Steam* ו-*Steam Inventory Helper* — לתוך קודבייס Manifest V3 אחד, נקי ומקורי, ללא שלב build וללא טלמטריה.

> תוסף לא רשמי. אינו קשור ל-Valve, Augmented Steam או Steam Inventory Helper.

הגרסה הנוכחית: **1.3.0** — ראו את [`CHANGELOG.md`](CHANGELOG.md) (באנגלית) לרשימה המלאה של השינויים.

## פיצ'רים

### דפי חנות (`/app/`, `/sub/`, `/bundle/`)
- 💸 **המחיר הנמוך ביותר כעת** בכל החנויות (דרך IsThereAnyDeal), עם אפשרות להצגת **מטבע נוסף**
- 📉 **שפל היסטורי** עם שם החנות, תאריך, ואחוז הנחה, וגרף sparkline מוטמע
- 🔔 **התראות מחיר** — קביעת מחיר יעד ישירות בדף המשחק (משותף עם התראות ה-wishlist) וקבלת התראה כשהוא מתקיים
- 🎁 **התראות על מבצעי חינם** לזמן מוגבל
- 🌍 **תצוגת מחירים אזוריים** (ארה"ב, ארגנטינה, טורקיה, רוסיה, הודו, ברזיל)
- 🎒 **בדיקת חיסכון ב-Bundle** — קנייה נפרדת מול מחיר ה-bundle
- 🐧 **דירוג ProtonDB** לשחקני לינוקס/Steam Deck
- ⏱ קיצור דרך ל-**HowLongToBeat**
- 👥 **מספר משחקים כרגע**, 👫 **כמה חברים מחזיקים את המשחק** (אופציונלי, עם מפתח Steam Web API אישי)
- 🏆 **סטטיסטיקת הישגים** (כמות, הכי קל, הכי נדיר)
- 🧩 הדגשת **DLC בבעלות** + ספירה, הדגשת בעלות בתוך bundle
- 🃏 קישורי **קלפי מסחר** (Market + SteamCardExchange)
- 🔗 קישורים מהירים ל-SteamDB, SteamCharts, Barter.vg, SteamSpy, SteamGifts, SteamTrades
- 📊 פירוט ביקורות, **קטע הביקורת המועילה ביותר**, **דגל "ביקורת-בומבה" אפשרית**, ו**סרגל סינון חי** (שעות משחק מינימליות, אורך מינימלי, מומלץ/לא) שמסנן ביקורות טעונות בלי לרענן את הדף
- 📝 הערות פרטיות לכל משחק, תגיות DRM/גישה-מוקדמת/בקרוב, תגיות קהילה

### דפי חיפוש, מבצעים, סייל
- 🟩 הדגשת משחקים **בבעלות**, **ברשימת משאלות**, וש**התעלמת מהם**
- 🙈 אופציה **להסתיר בבעלות / להסתיר שהתעלמת מהם**, או להסתיר משחק בודד לצמיתות
- 🏷 תג **שפל היסטורי** על כל תוצאה

### רשימת משאלות
- 📤 ייצוא הרשימה ל-**CSV / JSON / טקסט**
- 🔍 פתיחה כמנה אחת ב-IsThereAnyDeal
- 🎯 **יעדי מחיר לכל שורה** עם התראות, מיון לפי הקרוב לשפל

### Steam Community Market
- 💰 הצגה אוטומטית של **הסכום נטו אחרי עמלת 15%** בכל listing
- ✂️ **מחשבון undercut**, 💹 **עוזר buy-order** (קורא את order book האמיתי)
- 💱 ממיר מטבעות מובנה

### מלאי (Inventory)
- 💎 **אמידת שווי מלאי** (עם גרף שווי לאורך זמן) · 👯 **מציאת/סימון כפילויות**
- 🗂 **מיון לפי שווי, קיבוץ לפי סוג, פירוט לפי rarity/quality**
- ☑️ **מכירה בבחירה ידנית מרובה** — בחירת פריטים, עריכת מחיר לכל אחד, אישור — או רישום אוטומטי לפי median (שניהם בתהליך דו-שלבי: תצוגה מקדימה ואז אישור מפורש, שום דבר לא נמכר בלי לחיצה מפורשת שלך)
- 🃏 התקדמות סטי קלפים, יוצר booster pack, מחירי מדבקות CS2 וקישורי inspect מדויקים

### עסקאות (Trade Offers)
- 📊 **טבלת שווי פריט-אחר-פריט** לכל צד, לא רק סכום כולל
- 🕓 **היסטוריית עסקאות מקומית** לכל שותף (מגמת פער השווי לאורך עסקאות בדפדפן הזה)
- 🛡 קיצורי דרך ל-SteamRep/Backpack.tf/SteamID.uk, כפתור אישור בהחזקה

### דפי פרופיל
- קישורי קיצור ל-**SteamDB calculator, SteamLadder, Backpack.tf, SteamRep**
- 📚 תמונת מצב של גודל/שווי הספרייה, 🏅 ספירת badges, 🖼 קישורי מדיה (screenshots/וידאו/artwork/workshop)

### דפי ספרייה (`/games/`) ו-Badges (`/badges/`)
- מיון לפי שעות משחק, סינון לא-שוחק, **אמידת שווי ספרייה**
- סיכום badges/XP לעמוד, רשימת הקרובים ביותר לעליית level

### כלל-דפדפני
- 🖱 **חיפוש מתפריט קליק ימני**, תג צף **SE** לגישה להגדרות, קיצורי מקלדת (`Ctrl+Shift+S/W/I`)
- ⚙️ עמוד הגדרות מלא + popup, עם **כ-35 מתגי פיצ'ר עצמאיים**
- 🌐 מדינה / מטבע / מטבע תצוגה ניתנים להגדרה
- 👋 סיור היכרות בהתקנה ראשונה, changelog בעדכון גרסה

## התקנה

### מחנות התוספים של Chrome
*(הרשמה בתהליך — ראו `store-assets/` לחבילת ההגשה.)*

### התקנה ידנית (מצב מפתח)
1. שכפלו/הורידו את הריפו.
2. גשו ל-`chrome://extensions/`.
3. הפעילו **מצב מפתח**.
4. לחצו **Load unpacked** ובחרו את תיקיית הריפו.
5. פתחו כל דף חנות/קהילה של Steam — יופיע תג **SE** בפינה הימנית-תחתונה.

## פרטיות

Steam Enhancer **לא אוסף, לא מעביר, ולא מוכר שום מידע אישי**. כל ההגדרות חיות ב-`chrome.storage.sync` ולא יוצאות מהדפדפן שלכם. פירוט מלא (באנגלית) ב-[`store-assets/privacy-policy.md`](store-assets/privacy-policy.md).
