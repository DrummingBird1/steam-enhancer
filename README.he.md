# Steam Enhancer

[![Manifest V3](https://img.shields.io/badge/Manifest-V3-blue)](https://developer.chrome.com/docs/extensions/mv3/intro/)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

**גרסה זו בעברית. הגרסה הראשית (אנגלית) נמצאת ב-[README.md](README.md).**

🗺 **מפת דרכים (באנגלית): [ROADMAP.md](ROADMAP.md).**

**Steam Enhancer** הוא תוסף Chrome כולל שמוסיף ל-Steam את הפיצ'רים האהובים ביותר מהתוספים *Augmented Steam* ו-*Steam Inventory Helper* — לתוך קודבייס Manifest V3 אחד, נקי ומקורי, ללא שלב build וללא טלמטריה.

> תוסף לא רשמי. אינו קשור ל-Valve, Augmented Steam או Steam Inventory Helper.

הגרסה הנוכחית: **1.5.0** — ראו את [`CHANGELOG.md`](CHANGELOG.md) (באנגלית) לרשימה המלאה של השינויים.

> **פיצ'רי המחיר דורשים מפתח API חינמי של IsThereAnyDeal** (המחיר הנמוך, השפל ההיסטורי, היסטוריית מחירים מלאה, תגיות מחיר בחיפוש וברשימת המשאלות, התראות על מבצעים). IsThereAnyDeal דורשים מפתח מכל אפליקציה שמשתמשת ב-API שלהם. רשמו אפליקציה חינמית ב-[isthereanydeal.com/apps/my/](https://isthereanydeal.com/apps/my/) והדביקו את המפתח ב-**אפשרויות ← מחירים ומפתחות**. בלי מפתח, הפיצ'רים האלה מציגים הודעה קצרה עם קישור לאפשרויות.

## פיצ'רים

### עמודי חנות (`/app/`, `/sub/`, `/bundle/`)
- 💸 **המחיר הנמוך כרגע** בכל החנויות ו**השפל ההיסטורי של Steam** (דרך IsThereAnyDeal), עם **מטבע תצוגה** נוסף לבחירה
- 📈 **גרף היסטוריית מחירים אינטראקטיבי**: המחיר ב-Steam בשלוש השנים האחרונות, תאריך ומחיר במעבר עכבר, טווחים של 3 חודשים / שנה / הכול, וקו בגובה המחיר הנמוך. בלי מפתח ITAD הגרף מציג את המחירים שראיתם בביקורים שלכם
- 🌍 **מחירים אזוריים במטבע שלכם**: תריסר אזורים מומרים למטבע אחד, מהזול ליקר, כל אחד מול המחיר שלכם
- 🔔 **התראות מחיר**: קובעים יעד ישר בעמוד המשחק (משותף עם רשימת המשאלות) ומקבלים התראה כשהמחיר מגיע אליו
- 🎒 **בדיקת חבילות**: קנייה בנפרד מול מחיר החבילה
- 🎮 **תאימות ל-Steam Deck** (מאומת / ניתן לשחק / לא נתמך) ו-🐧 **דירוג ProtonDB**
- 🏆 **סטטיסטיקת הישגים** (כמות, הכי קל, הכי נדיר) ו**ההתקדמות שלכם** במשחקים שבבעלותכם (עם מפתח Steam Web API שלכם)
- 👥 **שחקנים מחוברים עכשיו**, 👫 **כמה חברים מחזיקים במשחק** (אופציונלי, עם מפתח Steam Web API שלכם)
- 📊 פירוט ביקורות, **הביקורת המועילה ביותר**, **סימון חשד להפצצת ביקורות**, ו**סינון ביקורות חי** (שעות משחק, אורך, ממליץ או לא). כל אלה עובדים בכל שפה של Steam
- 🧩 סימון DLC שבבעלותכם, פריטים שבבעלותכם בתוך חבילות, תגיות DRM / גישה מוקדמת / בקרוב, תגיות קהילה
- 🃏 קישורים לקלפי מסחר, ⏱ HowLongToBeat, 🔗 SteamDB, SteamCharts, Barter.vg, SteamSpy, SteamGifts, SteamTrades
- 📝 הערות פרטיות לכל משחק

### חיפוש, מבצעים וסיילים
- 🟩 הדגשת משחקים **בבעלותכם**, **ברשימת המשאלות** ו**שהתעלמתם מהם**
- 🙈 הסתרת משחקים שבבעלותכם או שהתעלמתם מהם, או הסתרה קבועה של משחק בודד
- 🏷 **תגית שפל היסטורי** בכל תוצאה, באותו מטבע של המחיר שלידה

### רשימת משאלות
פאנל מעל רשימת המשאלות של Steam, שנבנה מהנתונים של Steam עצמו. עובד על כל רשימת משאלות ציבורית:
- 📋 טבלה אחת: מחיר, הנחה, שפל היסטורי וכמה המחיר מעליו, ביקורות, תאימות ל-Steam Deck, מחיר ההתראה שלכם, תאריך הוספה
- 🧮 סיכום: העלות הכוללת עכשיו מול מחיר מלא, וכמה משחקים במבצע, בשפל היסטורי, או הגיעו ליעד שלכם
- 🔎 חיפוש, 8 סוגי מיון, סינון (במבצע, בשפל היסטורי, הגיעו ליעד, מחיר מקסימלי)
- 📤 ייצוא של מה שמוצג ל-**CSV / JSON**, או העתקה כרשימה
- 🔔 בדיקה ברקע של **כל רשימת המשאלות** (עד 500 משחקים). כל מבצע מודיע פעם אחת

### Steam Community Market
- 💰 **כמה תקבלו בפועל** אחרי העמלות של Steam, בכל הצעה (לפי שיטת העיגול של Steam)
- 📋 **בדיקת ההצעות שלכם**: כל הצעה מסומנת כזולה ביותר או כנעקפה, ובכמה. אפשר לסמן את אלה שנעקפו ולהסיר אותן יחד
- ✂️ מחשבון עקיפה, 💹 עזרה בהזמנות קנייה (ספר ההזמנות האמיתי), 📈 גרף היסטוריית מחירים
- 💱 ממיר מטבעות

### מלאי
- ⚡ **מכירה מהירה** (סנט מתחת להצעה הזולה ביותר) ו**מכירה מיידית** (להזמנת הקנייה הגבוהה ביותר) לפריט שנבחר
- ☑️ **מכירה של כמה פריטים** ו**הצעה לפי חציון**: לכל פריט מוצג *הקונה משלם / אתם מקבלים* במטבע הארנק שלכם, ושום דבר לא מוצע למכירה בלי לחיצת אישור מפורשת
- 💎 הערכת שווי מלאי עם גרף לאורך זמן · 👯 כפילויות · 🗂 מיון לפי שווי, קיבוץ לפי סוג, פירוט נדירות
- 🃏 התקדמות סטים של קלפים, יוצר booster packs, מחירי מדבקות CS2 וקישורי inspect לפריט המדויק

### הצעות טרייד
- 📊 **טבלת שווי פריט-פריט** לשני הצדדים, כולל פריטים של Steam (קלפים, gems)
- 🕓 היסטוריית טריידים מקומית לכל שותף (פער השווי בהצעות שנראו בדפדפן הזה)
- 🛡 קיצורי דרך ל-SteamRep / Backpack.tf / SteamID.uk, כפתור אישור בלחיצה ממושכת

### פרופילים, ספרייה (`/games/`) ותגים (`/badges/`)
- קיצורי דרך ל-SteamDB calculator, SteamLadder, Backpack.tf, SteamRep; קיצורי מדיה
- מיון לפי שעות משחק, סינון משחקים שלא שוחקו, **הערכת שווי הספרייה**; סיכום תגים ו-XP

### בכל מקום
- 🔔 **מרכז התראות**: כל התראה נשמרת בחלון של הכפתור בסרגל עם מונה של התראות שלא נקראו. לחיצה פותחת את המשחק. אפשר להגדיר **שעות שקטות**
- ⚙️ **עמוד הגדרות** עם חיפוש, פרופילים מוכנים (מינימלי / צייד מבצעים / סוחר / הכול), שמירה אוטומטית, **גיבוי ושחזור** מלאים, ו-CSS מותאם
- 🖱 חיפוש מתפריט הקליק הימני, תג **SE** צף, קיצורי מקלדת (`Alt+Shift+S/W/D`)
- 🌐 המחירים לפי המדינה ש-Steam מציג לכם (או לפי בחירתכם); אנגלית, עברית (RTL), רוסית, גרמנית, פורטוגזית (ברזיל)

### התקנה ידנית (מצב מפתח)
1. שכפלו/הורידו את הריפו.
2. גשו ל-`chrome://extensions/`.
3. הפעילו **מצב מפתח**.
4. לחצו **Load unpacked** ובחרו את תיקיית הריפו.
5. פתחו כל דף חנות/קהילה של Steam — יופיע תג **SE** בפינה הימנית-תחתונה.

## פרטיות

Steam Enhancer **לא אוסף, לא מעביר, ולא מוכר שום מידע אישי**. ההגדרות והנתונים שהתוסף שומר בשבילכם נמצאים באחסון של Chrome עצמו ולא מגיעים אלינו. מכירה והסרה של הצעות ב-Market קורות רק בלחיצה שלכם, אחרי אישור שמראה בדיוק כמה הקונה משלם וכמה אתם מקבלים. פירוט מלא (באנגלית) ב-[`store-assets/privacy-policy.md`](store-assets/privacy-policy.md).
